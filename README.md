# transition

Gli script della transizione a inchiostro di **The Cape Studio**, fra la fine
dello scroll orizzontale e il carosello delle opere.

| File | Cosa è |
|---|---|
| `ink-transition.js` | la simulazione dell'inchiostro che copre la pagina |
| `cape-fold.js` | la piega del titolo nel titolo del carosello — vedi [`cape-fold.md`](cape-fold.md) |

`cape-ink-title.js` — il titolo disegnato come il buco che l'inchiostro non
riempie — non è nell'albero corrente: il sito lo serve da un commit più vecchio
di questa repo, agganciato per SHA. Sta lì, non è andato perso.

Si servono via jsDelivr agganciati allo SHA del commit, non a un ramo: così un
commit nuovo non cambia il sito finché non si aggiorna l'indirizzo a mano.
